End-to-End Machine Learning Project: Telco Customer Churn
From data to deployment with MLflow, FastAPI & AWS. This presentation walks through a complete ML solution that predicts customer churn, from initial data exploration to production deployment.


The Problem & Dataset
Churn represents customers who leave a service - a critical business
challenge since:
. Customer retention costs 5-25x less than acquisition
· Dataset contains ~28,000 customers with 20+ features
· Target variable: Churn (Yes/No)
· Features include demographics, contract types, usage patterns, and monthly charges
Dataset link: https://www.kaggle.com/datasets/blastchar/telco-customer-churn


Tools Overview

Our tech stack leverages industry-standard tools for each stage of the ML lifecycle:

Data Validation - Great Expectations ensures data quality and schema consistency

ML Tracking - MLflow logs experiments, metrics, and artifacts

Modeling - XGBoost classifier handles the binary prediction task

Serving - FastAPI provides REST endpoints and Gradio offers a web UI

Containerization - Docker packages the application for consistent deployment

Deployment - AWS ECS hosts the containerized application

2. Exploratory Data Analysis
Business metric to optimize - Recall
Recall - of all the customers who will churn , how many did we identify correctly? 
It calculates how many true churn cases were captured out of the total number of customers who actually churned, making it critical for ensuring at-risk customers are not missed.
Prioritizing recall often results in more false positives (flagging customers who would have stayed anyway), so the ideal balance depends on whether a business prefers to err on the side of missing churners or over-investing in retention efforts.

5. Serving Layer + UI [FastAPI (HTTP endpoint) + Gradio (UI)]


In our project, FastAPI acts as the serving layer, it turns our ML model into an API that can receive data and return predictions.
It's necessary because without it, the model would just sit in Python files, and no external app, script, or user could interact with it.

FastAPI Endpoint
